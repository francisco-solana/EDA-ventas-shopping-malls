# 🛍️ EDA - Ventas en Shopping Malls

Análisis Exploratorio de Datos + ETL de las ventas en centros comerciales.

---

## 📋 Descripción del Proyecto

Este repositorio contiene un **Análisis Exploratorio de Datos (EDA)** completo junto con un proceso de **ETL** (Extract, Transform, Load) sobre datos de ventas en shopping malls.

El objetivo principal es descubrir patrones de comportamiento de ventas, identificar tendencias temporales, correlaciones entre variables y generar insights accionables.

---

## 🎯 Objetivos

- Limpiar y transformar los datos crudos (ETL)
- Realizar un análisis exploratorio profundo
- Visualizar tendencias de ventas por mall, fecha, categoría, etc.
- Detectar outliers y oportunidades de negocio

---

## 🛠️ Tecnologías Utilizadas

- **Python**
- **Jupyter Notebook**
- **Pandas** (manipulación de datos)
- **Matplotlib + Seaborn** (visualizaciones)
- **NumPy** y otras librerías de análisis
